## 🌟 Overview

**Quran Quest: The Three Surahs Challenge** is an engaging, colourful, and interactive educational web application designed for schoolchildren to revise, understand, and master three essential chapters from their Islamic Studies curriculum:

1. **Level 1: Surah Az-Zalzalah (الزلزلة – The Earthquake)** *(Chapter 6)*
   - 8 verses revealed in Makkah.
   - The great shaking of the earth, throwing out treasures and the dead, body parts testifying, and reckoning down to an atom's weight (*mithqaala dharrah*).
2. **Level 2: Surah Al-Qadr (القدر – The Decree)** *(Chapter 5)*
   - 5 verses revealed in Makkah.
   - The descent of the Qur'an from *al-Lawh al-Mahfoodh* to *Baitul-'Izzah*, the odd nights of Ramadan, *I'tikaaf*, Angel Jibreel (*the Ruh*), and peace until dawn.
3. **Level 3: Surah At-Tin (التين – The Fig)** *(Chapter 4)*
   - 8 verses revealed in Makkah.
   - The four sacred oaths (The Fig, Olive, Mount Sinai where Allah spoke to Prophet Musa, and the Safe Land of Makkah), creation in the finest mould, and Allah as *Ahkamul-Haakimeen* (The Best of judges).
4. **Final Challenge: The Three Surahs Master Quiz**
   - Mixed comprehensive challenge testing the student's ability to distinguish and master concepts across all three Surahs.

## 🎮 Features

- **Islamic Educational Aesthetics:** Soft ivory layout adorned with SVG geometric arabesques, hanging *fanous* lanterns, crescent moons, and vibrant Islamic accents (emerald, turquoise, royal blue, and gold).
- **Gamified Progression:**
  - **Student Profile:** Custom name input and fun badge avatars (🌟, 🌙, 📖, 🌿, 🕌, 🕊️).
  - **Web Audio Sound Effects:** Synthesized cheerful chimes, soft clicks, and victory fanfares (zero external audio files needed; includes mute button).
  - **Dynamic Confetti Engine:** Multi-color star and ribbon confetti explosions upon correct answers and level completion.
  - **Badges & Stars:** Earn 1 to 3 stars per level and collect 4 unique achievement badges.
- **Three Core Question Types:**
  1. **✍️ One-Word Answers:** Flexible text input accepting spelling variants and ignoring casing/spaces.
  2. **🧩 Drag-and-Drop & Tap-to-Match:** Full drag-and-drop support plus **tap-to-pair** for tablets, iPads, and smartphones.
  3. **📝 Fill in the Blanks:** Interactive word-bank chips + direct typing into slotted blanks.
  4. **🔢 Ordering / Sequencing:** Arrange verses in order using draggable cards or quick up/down controls.
- **Teacher's Clue (Hint System):** Friendly contextual clues with exact textbook citations.
- **Detailed Instant Feedback:** Clear explanations with chapter citations on every question.
- **Official Printable Achievement Certificate:** Frame-ready certificate formatted with `@media print` displaying the student's name, completion date, final score percentage, and golden seal.
- **Comprehensive Answer Review:** Complete review modal with filters (*All*, *Correct*, *Needs Practice*).

## 🚀 How to Run

Because this project is built with Vanilla HTML, CSS, and JavaScript, it requires **zero installation** and works immediately in any modern web browser:

1. Clone the repository:
   ```bash
   git clone https://github.com/Fazi1329/grade_islam_worksheet_5.git
   ```
2. Open `index.html` directly in your browser:
   - Double-click `index.html`, OR
   - Run a lightweight HTTP server:
     ```bash
     python -m http.server 8080
     ```
     Then navigate to `http://localhost:8080/index.html`.
